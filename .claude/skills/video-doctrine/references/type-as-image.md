# Type as Image

Typography should occupy space, have depth, and participate in the action. In v1 it did
none of these: every one of nine beats was centred type entering on the same 4-point
opacity curve with the same 16px rise. Nine beats, one entrance.

## Type at a depth

Place type on a plane and let the camera move past it. It parallaxes with everything else
and stops reading as an overlay. D1's `Line` takes a `depth` and projects through the same
camera as the field, so a caption is a thing in the room.

## Masked reveals

Avoid the default left-to-right crop unless something causes it. Better reveal sources: a
passing light beam, a moving camera edge, a particle field, a shape crossing the letters,
a route drawn through the word, a focus pull from blur to sharp.

**The reveal should be caused by something inside the world.** Our `Line` wipes with a
`clip-path` inset so the word is uncovered rather than faded.

## Kinetic typography that means something

Movement should express the word: "flow" travels, "precision" snaps into alignment,
"scale" expands past the frame, "together" assembles from parts, "signal" pulses.

## Type entering from depth

Instead of sliding in from the side: place it far behind the hero, push the camera toward
it, let it pass behind a foreground layer, scale it by perspective, let it overshoot the
camera and leave frame. This makes type feel like architecture.

## Scale hierarchy

Use several simultaneously: one oversized word cropped by the frame · one medium word
integrated with the system · tiny mono type as texture and metadata · one clean readable
lockup at the end. **The viewer should not be reading every text element.** Most type
functions as shape, rhythm and scale.

## Budget for a 25-second film

One core message. One supporting phrase if genuinely needed. One brand lockup. Everything
else non-verbal.

If a line needs more than a glance, it belongs in the long cut.

## The test (doctrine S2)

Delete the line. Does the beat still read?

- **still reads** → the picture is carrying it; the line is optional polish
- **becomes meaningless** → the picture is not doing its job, and the fix is the picture

There is no detector for this one. It is reported as `no-detector` rather than quietly
skipped, because a doctrine that hides which clauses it cannot check is worse than a
shorter doctrine.
